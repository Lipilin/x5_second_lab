## Вопрос 5
Будет выведена ошибка RuntimeWarning: coroutine 'work' was never awaited
  work(i + 1)
RuntimeWarning: Enable tracemalloc to get the object allocation traceback
Поскольку вызов асинхронной функции не сопровождается ее мгновенным исполнением, создается лишь объект корутины. Для запуска исполнения корутины необходимо ключевое слово await. Интепретатор жалуется, что мы создали объект корутины, но никогда не ожидали(а следовательно и не запускали) исполнения
Выводит: <coroutine object work at 0x7b3ffcf01630> - объект корутины

## Вопрос 6
Event loop содержит список всех активных задач. Когда первая задача доходит до asyncio.sleep она возвращает управление потоком event loop, event loop запускает другие задачи. Event loop будет работать до тех пор пока есть не завершенная задача(в данном случае)
